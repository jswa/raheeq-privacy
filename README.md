# سياسة الخصوصية - تطبيق الرحيق المختوم
### Privacy Policy - Ar-Raheeq Al-Makhtum Reader

وثيقة سياسة الخصوصية الرسمية لتطبيق **«الرحيق المختوم»** لقراءة وبحث السيرة النبوية المطهرة.

🌐 **رابط الموقع المباشر:** [https://jswa.github.io/raheeq-privacy/](https://jswa.github.io/raheeq-privacy/)

- يعمل التطبيق دون اتصال بالإنترنت (Offline).
- خالٍ تماماً من الإعلانات وحزم التتبع.
- لا يجمع أي بيانات شخصية أو معرّفات أجهزة.
- آمن لجميع أفراد الأسرة.
